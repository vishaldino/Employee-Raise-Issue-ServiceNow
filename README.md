# Employee Raise Issue – ServiceNow

## About the project

This project is a ServiceNow solution for handling workplace issues raised by employees. The idea is to replace scattered email or informal requests with one simple place where an employee can submit an issue and provide the details needed by the support team.

The project uses the **Employee Center** scoped application and a custom **Employee Raise Issue** table. Employees submit issues through a **Raise Employee Issue Record Producer** in the Service Portal.

## Main features

- Employee Raise Issue custom table
- Raise Employee Issue Record Producer
- Service Portal entry point
- Category and subcategory selection
- Requester and short description
- Issue state and priority information
- Attachments
- UI Policy for a read-only Number field
- UI Policy that requires Short description when State is New
